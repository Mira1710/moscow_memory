# Мобильная карта

Мобильная вёрстка главной страницы вынесена в `app/assets/stylesheets/mobile_map.css` и применяется до 767 px. Правила ограничены `.moscow-memory.map-page`, поэтому не меняют админку и страницу «О нас». Propshaft подключает файл вместе с остальными стилями через `stylesheet_link_tag :app`.

- Шапка: монограмма `app/assets/images/mobile-logo.svg`, название страницы и кнопка меню. Ссылки используют существующий общий partial `app/views/shared/_sidebar.html.erb`.
- На первом экране вводные карточки скрыты, карта занимает всю доступную ширину. Фильтры и интервалы открыты по умолчанию, их можно свернуть. Большой список меток прокручивается внутри своей панели.
- Шкала по умолчанию показывает 2000–текущий год с шагом 10 лет. При выборе шага 50 лет начинается с 1900 года. Шаг в 1 год и длинные истории доступны горизонтальным свайпом по годам.
- Открытая статья занимает ширину экрана под компактной картой; прокручивается только статья. Крестик возвращает большой экран карты. ResizeObserver сообщает Яндекс Картам об изменении размеров контейнера.
- Десктопная карта и панель справа сохраняют свою раскладку.

Размеры шапки и карты регулируются переменными `--mobile-header`, `--mobile-gutter`, `--mobile-map-height` в отдельном CSS. Логотип для телефона можно заменить своим SVG, сохранив имя `mobile-logo.svg`.

Проверка: `bin/rails test:system`. Тест проверяет ширины 320, 390, 430 px с эмуляцией мобильного viewport, меню, интервалы, отсутствие горизонтального переполнения, открытие/закрытие статьи и неподвижность карты при прокрутке текста. Тесты не используют рабочий ключ Яндекса.
