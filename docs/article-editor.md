# Редактор статей

1. Откройте /admin и войдите в аккаунт автора. При первом локальном входе создайте аккаунт.
2. Заполните название, категорию метки, адрес и координаты. Без координат статья сохранится, но точки на карте не будет.
3. Добавьте основной текст и обложку.
4. Нажимайте «Добавить исторический период»: название, даты, текст, несколько фото. «Убрать этот период» удалит его при сохранении.
5. Загрузите архивные фото, карты/планы и изображения предметов. Добавьте источники, каждый с новой строки.
6. Нажмите «Сохранить статью». Данные сразу используются на странице объекта, в списке статей и в правой панели главной карты после открытия/обновления страницы.

Поддерживаются JPG, PNG, WebP, GIF. Новые фотографии добавляются к имеющимся. Галочки «Удалить фото» убирают выбранные изображения при сохранении. Текст вводится обычным текстом; разметка HTML из текста не исполняется. Если форма содержит ошибки, введённые данные и загруженные фото сохраняются в форме для исправления.

Метаданные и имена изображений хранятся в PostgreSQL, файлы — в public/uploads. Существующая загрузка обложек CarrierWave сохранена, добавлены галереи на том же механизме. Миграция 20261025000100 добавляет поля к Place и HistoricalState; существующие поля, ID и связи остаются.

SVG категорий берутся из assets/images/markers. Назначать категорию теперь нужно в форме, а не в map_places.yml. Поддерживается имеющееся имя estate.svg для категории «Усадьбы», а также estates.svg. Индивидуальная метка markers/places/ID.svg имеет приоритет.

Старые файловые настройки config/map_places.yml и content/articles больше не используются. На момент перехода они не содержали пользовательских статей/настроек, только инструкции и пустой YAML.

Для GitHub Pages понадобится отдельно реализовать экспорт базы и изображений в статические файлы и публиковать его заново после изменений. Этот редактор работает в Rails.

Дополнительные блоки каждого периода «Сохранившееся» и «Утраченное» включаются галочками. Инструкция входа — docs/admin.md. Публичные страницы доступны только для чтения без входа.
