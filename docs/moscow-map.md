# Карта архитектурной памяти Москвы

Главная страница использует существующие Place и HistoricalState. Модели, routes.rb, схема и данные не изменены. HomeController теперь загружает все объекты и заранее загружает historical_states вместо ограничения тремя записями.

Из moskvedenie.zip перенесены логотип, оформление бокового меню, вводные карточки, цвета, сетка и оформление прокручиваемой статьи. Отдельный TCP-сервер, SVG-карта, демонстрационные статьи, неподключённая подписка и фиктивные разделы не перенесены. Категорий в схеме Rails нет, поэтому фильтры категорий не подменены выдуманными данными. Вместо них доступны реальные объекты, временная шкала и режим «Все эпохи».

## Запуск

В терминале в папке существующего проекта:

```sh
export YANDEX_MAPS_API_KEY='ваш реальный ключ'
bin/rails server
```

Ключ не добавлен в исходники. `.env.example` — образец, он не загружается автоматически. Нужен ключ JavaScript API Яндекс Карт, ограниченный разрешёнными доменами в кабинете разработчика. Браузерный ключ передаётся клиенту по назначению API.

Без ключа или при ошибке загрузки показывается сообщение; статьи открываются из списка. API 2.1 загружается только для страницы карты. Старое подключение Leaflet удалено из layout, поскольку другие представления его не используют.

Документация API: https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/dg/concepts/load

## Поведение

Клик по метке открывает справа статью из Rails. Панель располагается поверх правой части карты, не меняя её размеры, центр или масштаб. Прокручивается область статьи. Крестик и Escape закрывают панель. На узком экране карта остаётся видна слева. Временная шкала учитывает year_from/year_to включительно; неизвестная граница не ограничивает период. Исторические состояния выбранного года выделяются внутри статьи. Объекты без корректных координат доступны в списке, но метки для них не создаются.

Stimulus создаёт карту при подключении страницы и уничтожает при уходе или сохранении Turbo-кэша. Тексты статьи отрисовываются ERB с экранированием и simple_format, без вставки необработанного JSON/HTML из базы.

## Проверки

- Rails: тест главной страницы, объектов и истории из базы, экранирования названий.
- Chrome: панель справа, неизменный размер и положение карты, прокрутка статьи 600 px при window.scrollY = 0, закрытие Escape, повторное открытие после перехода в архив и возврата Turbo; проверены размеры 1440×900 и 390×844.
- Обработчик клика по метке проверен с тестовым заменителем API на трёх координатах из рабочей базы. Живая загрузка карты и корректность реального ключа не проверены: ключ не предоставлен.
- Миграции и загрузка seeds не запускались. Рабочая база использовалась только для чтения.
