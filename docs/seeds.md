# Посевное наполнение и демонстрация

## Запуск

```sh
bin/rails db:migrate
bin/rails db:seed
```

Скрипт `db/seeds.rb` вызывает `DemoContent.load!` из `app/services/demo_content.rb`. Он добавляет три примера: парк «Зарядье», Дом Мельникова и Шуховскую башню. У них есть координаты, категории, тексты, ссылки на источники и четыре исторических периода суммарно.

Идентификатор `places.seed_key` отличает примеры от авторских материалов. Существующая запись с тем же ключом пропускается целиком: повторный запуск не меняет текст, фото и периоды даже после редактирования через админку. Статьи без ключа не затрагиваются. Если удалить пример через админку, следующий запуск создаст его заново. Ошибка прерывает наполнение целиком в транзакции.

Фотографии не скачиваются с чужих сайтов и не выдаются за исторические материалы. Добавьте свои файлы через `/admin` → «Редактировать статью»: обложка, фотографии периода, сохранившегося/утраченного и разделы архива. Имена файлов хранятся в базе, сами файлы — в `public/uploads`.

Не используйте `db:reset`, `db:seed:replant` или `db:drop` для демонстрации на своей наполненной базе: эти команды очищают данные. Для повторного безопасного показа достаточно `db:seed`.

## Что показать по требованиям 12, 14, 18, 19, 20

1. Откройте `/`: заглушка, карта, меню, временная шкала с интервалами 50/10/1 год. Для настоящей карты нужен `YANDEX_MAPS_API_KEY` с разрешённым доменом.
2. Откройте `/about`: свёрстанная страница о проекте и последовательность блоков.
3. В `/admin` создайте статью с координатами, категорией, обложкой и историческим периодом. Включите нужные блоки «Сохранившееся»/«Утраченное» и сохраните.
4. Обновите главную: откройте статью через метку или список объектов; статья прокручивается справа, карта остаётся на месте. Закройте крестиком или Escape.
5. В админке измените текст и фото. Проверьте публичную статью после обновления. Удаляйте только специально созданную демонстрационную статью.
6. Покажите `db/seeds.rb`, `app/services/demo_content.rb` и миграцию `seed_key`. Запустите `db:seed` дважды: первый раз добавляются недостающие примеры, второй раз — ноль; авторские правки остаются.
7. Выйдите из админки: открывается вход, создание/изменение/удаление без входа запрещено. Публичные статьи доступны посетителям.

## Автоматическая проверка

```sh
bin/rails test
bin/rails test:system
bin/rubocop
bin/bundler-audit
bin/brakeman --no-pager
bin/importmap audit
```

Обычные тесты проверяют доступ, редактор, галереи, удаление и повторяемость сидов. Системные тесты запускают отдельный headless Chrome и тестовую базу: создание/изменение/удаление статьи с фото, панель, скролл, интервалы, мобильную страницу о проекте. Для проверки обработчика метки используется тестовый заменитель Яндекс API; это не проверка действительности ключа или доступности Яндекса.

Форма подписки сохраняет почту в базе и показывает подтверждение. Список доступен только автору в разделе «Подписчики». Отправка уведомлений ещё не подключена. Маршруты и форум пока не реализованы как самостоятельные сервисные функции.
