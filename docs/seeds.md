# Посевные данные

```sh
bin/rails db:migrate
bin/rails db:seed
bin/rails test test/seeds_test.rb
```

Данные и логика наполнения находятся в `db/seeds.rb`. Скрипт добавляет три объекта и четыре исторических периода. `seed_key` отличает посевные записи от материалов, добавленных через админку.

Повторный запуск не меняет уже существующие записи и авторские правки. Тест `test/seeds_test.rb` проверяет результат наполнения и повторный запуск.

Команды `db:reset`, `db:drop` и `db:seed:replant` удаляют данные; для повторного наполнения используется `db:seed`.
