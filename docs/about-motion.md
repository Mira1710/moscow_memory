# Анимация страницы «О нас»

Оформление — `app/assets/stylesheets/about_page.css`, содержимое — `app/views/pages/about.html.erb`, привязка к прокрутке — `app/javascript/controllers/about_story_controller.js`.

- Внешняя рамка закреплена на оболочке страницы; секции идут в обычном потоке без перекрытия. Сетка не движется при прокрутке внутренней колонки.
- Вступление: внутри закреплённого фрейма заголовок опускается на 62 px к тексту, знак вопроса исчезает, мост «тогда — сейчас» расширяется и раскрывает годы и периоды.
- Источники: пять изображений выровнены в один ряд и перемещаются общей группой по диагонали вправо-вниз, без задержек и ступенек. Положение вычисляется из текущего скролла, поэтому обратная прокрутка точно возвращает их вверх.
- Карты: три внутренних фрейма в одной сцене сменяются по скроллу. Вторая карта и её текст поднимаются поверх первой, затем поверх них появляется «А что ещё?» с подпиской. Карты и текст выровнены по центру сцены. Неактивный фрейм исключён из фокуса клавиатуры и чтения экранным диктором.
- Основной текст: Geologica ExtraLight, `font-weight: 200`. Акцидентные заголовки остаются Aempirial.

Длительность задаётся высотой `.about-intro`, `.about-history`, `.about-map-story`. Амплитуды и пороги — в `paint()` контроллера. Обработчик скролла пассивный, изменения сгруппированы в `requestAnimationFrame`; изображения и текст двигаются через transform/opacity. При предпочтении reduced motion текст и изображения доступны без обязательной анимации, все три картографических фрейма идут последовательно.
