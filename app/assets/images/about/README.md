# Изображения страницы «О нас»

Положите в эту папку файлы с точными названиями:

1. archive-photo.jpg — старая фотография здания.
2. archive-map.jpg — старая карта/план Москвы.
3. archive-paper.jpg — историческая газета, журнал или книга.
4. artifact.jpg — исторический предмет/артефакт.
5. bell.jpg — колокол.
6. map-categories.jpg — иллюстрация карты с категориями меток.
7. map-history.jpg — иллюстрация карты с названиями мест и их датами.
8. map-launch.jpg — карта для фонового изображения карточки «Скоро запуск!».

Первые пять изображений отображаются квадратами. Изображения карты лучше подготовить шириной не менее 1000 px. Используйте изображения, которые вы вправе публиковать. После добавления обновите страницу; при публикации потребуется новая сборка assets. До добавления изображений показываются подписанные нейтральные места.
