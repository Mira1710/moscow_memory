# Изображения карточек маршрутов

Положите сюда свои фотографии под следующими именами:

| Карточка | Файл |
| --- | --- |
| Хамовники | khamovniki.jpg |
| Чертаново | chertanovo.jpg |
| Пожар 1812 | fire-1812.jpg |
| Перемены 1917 | changes-1917.jpg |
| Рабочий 1910 | worker-1910.jpg |
| Библиотекарь 1980 | librarian-1980.jpg |

Рекомендуемый размер: от 900×600 px, горизонтальное изображение. Фото заполняет карточку через `object-fit: cover`; края могут обрезаться. Если важна другая точка кадрирования, добавьте `object-position` в `routes_page.css`.

Названия файлов, тексты и подписи меняются в `config/walking_routes.yml`. Можно указать `.png` или `.webp`, изменив имя в YAML. После добавления обновите страницу. Пока файла нет, показывается оформленная заглушка без сломанного изображения.

Для параметров маршрута добавьте к карточке `duration: "1 ч 20 мин"` и `distance: "3,5 км"`, используя свои рассчитанные значения. Пока значения не заданы, выводится «уточняется». Приведённые здесь числа — пример формата, они не загружаются на сайт.
