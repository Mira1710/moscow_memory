# Фотографии теперь загружаются через редактор

Откройте /places/:id/edit и выберите файлы в полях обложки, исторического периода или архива.
Файлы копируются в public/uploads; имена сохраняются в базе данных. При редактировании новые фото добавляются к старым. Для удаления используйте галочку рядом с фото.
Папки assets/images/articles/ID больше не используются статьями. Они сохранены для справки. SVG меток остаются в assets/images/markers.
