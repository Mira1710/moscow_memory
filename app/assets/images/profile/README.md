# Изображения профиля

Общая временная обложка аватара: `app/assets/images/profile/avatar.jpg`.
Если файла нет, показывается первая буква имени. Этот файл служит общей иллюстрацией, а не личным аватаром каждого пользователя.

Фотографии маршрутов и архива добавляются через «Предложить маршрут» / «Пополнить архив» в профиле. Файл сохраняется в `public/uploads/profile_submission/image/<id>/`; название и описание — в PostgreSQL.

Новые аккаунты пустые: данные чужого демонстрационного профиля не подставляются. Избранные статьи добавляются кнопкой «В избранное» на странице статьи.
