# Изображения разделов каталога статей

Добавьте сюда горизонтальные изображения:

- `districts.jpg` — карта или изображение для «Округа и районы».
- `vanished.jpg` — изображение для «Исчезнувшее».
- `archive.jpg` — изображение для «Архив».

Рекомендуемый размер — от 1000×400 px. Названия и расширения можно изменить в `config/article_catalogue.yml`. Пока файла нет, видна клетчатая заглушка.

Вёрстка и анимация: `app/assets/stylesheets/articles_page.css`. Карточки ведут к реальным материалам темы. Тема назначается статье в админке полем «Тема в каталоге статей»; без темы материал остаётся в общем списке внизу страницы. Существующие статьи автоматически по темам не распределяются.
