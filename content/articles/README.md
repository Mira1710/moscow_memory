# Тексты теперь редактируются через формы

Откройте /places, выберите объект и нажмите «Редактировать статью».
Тексты, даты, категория и источники сохраняются в базе Rails.
Файлы intro.txt/state-ID.txt/sources.txt больше не читаются при отображении статьи.
Эта папка сохранена для справки; новые тексты сюда добавлять не требуется.
